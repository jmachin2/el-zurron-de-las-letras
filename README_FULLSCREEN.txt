EL ZURRÓN DE LAS LETRAS · FULLSCREEN PERSISTENTE

CAMBIO PRINCIPAL
- Solo existe un botón PANTALLA COMPLETA: el botón global de la barra superior.
- Los botones fullscreen internos de todos los juegos/pantallas quedan ocultos.
- La navegación M / S / juegos / cuento se realiza dentro del mismo documento superior.
- Al navegar, cambia la URL mediante History API, pero el documento fullscreen NO se recarga.
- Por eso la pantalla completa permanece activa hasta usar SALIR DE PANTALLA COMPLETA.

URLs:
/
/m/
/m/centro/
/m/mision/
/s/
/s/centro/
/s/mision/
/s/cuento/

NOTA DEL NAVEGADOR
La tecla Esc o los controles propios del navegador siempre pueden cancelar pantalla completa
por razones de seguridad; una web no puede desactivar esa salida del navegador.
