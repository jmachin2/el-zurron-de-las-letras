EL ZURRÓN DE LAS LETRAS · M + S + L
PAQUETE PREPARADO PARA GITHUB PAGES

IMPORTANTE:
GitHub NO descomprime un ZIP dentro del repositorio automáticamente.
Primero descomprime este ZIP en tu ordenador y sube TODO su contenido
a la raíz del repositorio.

DEBE QUEDAR EN LA RAÍZ:
- index.html
- 404.html
- .nojekyll
- carpeta assets
- carpeta app-content
- carpetas m, s y l

DESPUÉS:
1. En GitHub abre el repositorio.
2. Sube todos los archivos y carpetas.
3. Ve a Settings > Pages.
4. En Build and deployment selecciona:
   Deploy from a branch
5. Branch: main
6. Folder: / (root)
7. Guarda.

La web está preparada para funcionar tanto en:
https://USUARIO.github.io/
como en un repositorio de proyecto:
https://USUARIO.github.io/NOMBRE-REPOSITORIO/
